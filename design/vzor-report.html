02Obmedzenia API — čo je vôbec možné

Tri tvrdé obmedzenia eshop API určili celú architektúru. Appka nemôže vedieť viac, než si sama zapíše.

01Jediný write

setReduction je jediný zápis

POST /api/products/setReduction — len percentuálna zľava s časovým oknom. Strop 30 %, okno max 3 mesiace. Fixné reduction_price zápis naopak maže. Nie je batchable: 10 produktov = 10 requestov, pri chybe v strede kompenzácia, nie rollback.

02Nezvratné

Zľavu nie je možné zmazať

reduction musí byť > 0 — jediné „zrušenie“ je nastaviť to do minulosti, čo je hack, nie API funkcia. Rozhodnutie: zľavy sa nerušia, len expirujú. Hack sa neimplementuje.

03Slepé čítanie

API nevracia aktuálnu zľavu

GET /api/products ani /get nevracajú stav zľavy. Appka pozná len to, čo sama zapísala — audit log je jediný zdroj pravdy. Čítacie endpointy sú verejné bez auth, takže read časť funguje aj po expirácii kľúča.

05Najvážnejšie nálezy a pasce

Všetky nálezy nižšie by prežili do produkcie — testy ich maskovali alebo vznikli až v reálnom prostredí.

E1Kritické

Scheduler nikdy nezapisoval

Executor zapojený cez as cast na nekompatibilnú signatúru + dynamický import, ktorý v standalone Node vrátil null. Každý automatický fire končil needs_key. Poučenie: aspoň jeden test s produkčným adaptérom, fake maskuje wiring.

E5Pasca DB

MariaDB potichu skráti dátumový sentinel

new Date(8.64e15) sa serializuje ako rok 275760 a MariaDB ho s warningom skráti — porovnanie fire_at <= ? vracia vždy false, bez chyby. In-memory fake sentinel zvládol, reálna DB nie.

P1Blokujúce

Absolútny prepis mazal správne dáta

Pri rate limite prvého requestu replaceDayUnits(day, []) zmazal už uložené kusy — appka by bola tichým generátorom nepravdivých núl. Upsert bez ochrany „nikdy nezhorš dáta“ je pasca.

TPKompilátor

Turbopack zahodil null-guardy

if (!row) vyhodnotený ako compile-time falsy — GET /api/key padal na 500 pri každom prvom spustení. Fix: explicitné row === null. Rovnaká trieda chyby ako E1.

WWindows

Tri pasce nasadenia na Windows

CRLF v .sh zhodí kontajner (shebang s \r nie je cesta); Docker Desktop hlási 777 na bind mountoch → tajomstvá do named volume, invariant sa neoslabuje; PowerShell 5.1 číta .ps1 bez BOM ako ANSI.

SČisté

Bezpečnostná vrstva vyšla z honu čistá

I1/I2/I3 centrálne fail-closed, jediný nález nízkej závažnosti (X-Forwarded-For — brať pravý token). Architektúra preview tokenu + guardov sa osvedčila.

07Definície a obmedzenia vzorky

Invariant
Pravidlo vynútené schémou, kódom alebo grep testom, ktorého porušenie zhodí build alebo testy — nie konvencia. Appka ich má 14 + I8′ z predajnosti.
Preview token
Jednorazový HS256 JWT s TTL 15 minút, nesúci SHA-256 hash kanonickej sady produktov a cenu pri preview. Bez platného tokenu neexistuje zápis do shopu.
Dry-run
Povinný default: zápisy do produkčného shopu sú vypnuté, kým používateľ operáciu výslovne nepotvrdí a WRITES_ENABLED nie je true.
Failing-first test
Test napísaný tak, aby pred opravou padal a po nej prešiel — dôkaz, že oprava rieši reálny defekt, nie symptóm.
Runaway strop
Maximálne 60 zápisov za hodinu, počítané dotazom nad append-only audit logom — nedá sa obísť resetom počítadla.
